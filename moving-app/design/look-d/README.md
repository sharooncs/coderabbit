# Look D, "Night house"

The visual target for HouseMove 2.0: a dark, glassy look with a lit model house.

- `look-d.png` shows the two reference screens side by side: Home (left) and Rooms (right).
- `D-Home.dc.html` and `D-Rooms.dc.html` are the mock-ups those pictures were made from.
  They are plain HTML with inline styles, so every colour, gradient, corner radius,
  shadow and the corner points of the two house drawings can be read straight from them.

These files are reference only; nothing in the app loads them.
